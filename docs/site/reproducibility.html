Reproducibility and figure provenance

This repository publishes selected, source-attributed visual evidence. It is not the original research dataset or a runnable inference package.

Where the figures come from

  • The Court geometry and CurrentCourt count map are from a separate August 7 source-bound checkpoint study.
  • The Pose, candidate, state-timeline, and boundary screenshots are frozen visualizations from the October 3 four-source cohort.
  • The Tail-safe probability plot, model-performance chart, and boundary feature profile are existing offline report figures.
  • The archived ablation chart is a separate table-derived study record; it does not share the Tail-safe metric denominator.
  • The TrackNet scatter is the original high-resolution raw-candidate figure. Its points are not connected into tracks.

Images are reused as-is; this site does not create synthetic detections, trajectories, GT rows, or confidence curves.

Evidence manifest

The machine-readable evidence manifest records each figure's asset path and dimensions, source binding where applicable, source time and PTS for sampled frames, model or stage, experiment status, supported claim, limitation, and provenance.

The technical details are available from each figure's expandable caption. The main page keeps those fields out of the reading path while preserving access for researchers.

Public package boundary

The site deploys from docs/site/ using an exact positive file allowlist. The public bundle contains selected still images, report figures, explanatory pages, and aggregate comparison metrics. It excludes source video and proxies, private checkpoints, model caches, raw candidate tables, annotation and review files, identity data, and local service payloads.

The repository-level ALLOWLIST.json and the site-level public asset list define separate source-control and Pages boundaries.

What can and cannot be reproduced here

  • Readers can inspect each published image at its original stored resolution and trace its documented claim to the manifest.
  • The two offline arms' aggregate metrics can be compared from the published data file and source report.
  • The repository checks validate the public payload, image files, links, study metrics, and bilingual routes.
  • The numerical evaluation and inference cannot be rerun from this repository alone because source video, raw caches, weights, and annotation files are not included.

Study separation

The October 3 visual cohort, October 12 fusion evaluation, August 7 Court checkpoint, and October 13 archived ablation have different protocols and purposes. Their figures must not be combined into a fictional single execution. The editorial reference does not establish physical shuttle or Hit truth, and the same-date study does not establish cross-date generalization.

Production status

EventFirst remains the implemented production path with status PRODUCTION_NOT_READY. The public offline results report zero accepted production Rally intervals, zero accepted KeepTimeline outputs, and zero new exports. Nothing in this gallery certifies a production automatic editor.
